# freshmart-complete-food-ordering-project

A modern React-based food ordering website with product search, filtering, basket, checkout, order confirmation, and delivery tracking.

## FreshMart Food Product Explorer

A React + TypeScript + Vite food shopping demo.

## Features
- FreshMart food product explorer using DummyJSON grocery data
- Search, category and rating filters
- Food product details
- Add to basket with quantity controls
- Basket persistence with localStorage
- Checkout and delivery address form
- Demo order confirmation
- Delivery tracking page
- Responsive FreshMart design with Manrope + DM Serif Display fonts

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite (usually `http://localhost:5173`).

## Build

```bash
npm run build
```

This is a front-end demo. Checkout does not process real payments or create real delivery orders.
